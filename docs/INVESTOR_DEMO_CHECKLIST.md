# Investor Demo Checklist

## Pre-Demo Preparation

### Technical Setup
- [ ] All services running and healthy
- [ ] Database seeded with demo data
- [ ] SSL certificate valid
- [ ] Domain pointing correctly
- [ ] Backup system tested
- [ ] Monitoring alerts configured

### Demo Data
- [ ] 3-5 sample estate plans created
- [ ] Each estate plan has 2-3 beneficiaries
- [ ] Timelock policies configured
- [ ] Demo user account ready
- [ ] Test Bitcoin addresses (testnet)

### Content & Documentation
- [ ] Pitch deck prepared
- [ ] Demo script written
- [ ] FAQ document ready
- [ ] Technical architecture diagram
- [ ] User flow diagrams

## Demo Flow

### Opening (2 minutes)
- [ ] Show live application URL
- [ ] Demonstrate responsive design (mobile view)
- [ ] Highlight professional UI/UX

### Core Features Demo (10 minutes)
- [ ] **Estate Plan Creation** (2 min)
  - [ ] Create new estate plan
  - [ ] Add Bitcoin address
  - [ ] Set description
  - [ ] Show instant save
  
- [ ] **Beneficiary Management** (3 min)
  - [ ] Add multiple beneficiaries
  - [ ] Set allocation percentages
  - [ ] Show validation (total must be 100%)
  - [ ] Edit/delete beneficiaries
  
- [ ] **Timelock Policies** (3 min)
  - [ ] Create timelock policy
  - [ ] Set block count
  - [ ] Choose trigger condition
  - [ ] Activate/deactivate
  
- [ ] **Dashboard Overview** (2 min)
  - [ ] Show statistics
  - [ ] Display charts
  - [ ] Recent activity feed

### Chatbot Demo (5 minutes)
- [ ] Ask: "What is a Bitcoin timelock?"
- [ ] Ask: "How do I set up an estate plan?"
- [ ] Ask: "What happens when a timelock activates?"
- [ ] Show conversation history
- [ ] Demonstrate helpful guidance

### Technical Highlights (3 minutes)
- [ ] Show API documentation (Swagger)
- [ ] Demonstrate real-time updates
- [ ] Show mobile responsiveness
- [ ] Highlight security features

### Q&A Preparation
- [ ] Scalability plan ready
- [ ] Security measures documented
- [ ] Monetization strategy prepared
- [ ] Roadmap for next 6 months
- [ ] Team/development capacity

## Post-Demo

- [ ] Collect feedback
- [ ] Follow up with materials
- [ ] Schedule technical deep-dive if needed
- [ ] Update roadmap based on feedback
